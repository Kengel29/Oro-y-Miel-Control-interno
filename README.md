# Oro y Miel · Control interno

Página web para controlar inventario, precios, márgenes de ganancia, caja diaria y cierres de la pastelería Oro y Miel.

Funciona en celular y computadora. Los datos se guardan en el navegador del dispositivo (localStorage); usa "Copiar respaldo" en Reportes para guardarlos.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube el archivo `index.html`.
3. Ve a Settings, luego Pages.
4. En Source elige "Deploy from a branch", rama `main`, carpeta `/ (root)`, y guarda.
5. En 1 o 2 minutos tendrás un enlace como `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
